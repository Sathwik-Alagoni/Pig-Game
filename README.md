# Dice Game

A simple two-player dice game where players take turns rolling a dice, accumulating their current scores, and holding to add to their total scores. The first player to reach or exceed 100 points wins the game.

---

## Live Demo

Play the game live here: [Dice Game on Netlify](https://your-netlify-link.netlify.app)

---

## Features

- **Dice Rolling:** Players can roll a dice to add to their current score.
- **Hold Mechanic:** Players can hold to save their current score to their total score and pass the turn to the other player.
- **Winner Declaration:** The game declares the winner when a player’s total score reaches or exceeds 100.
- **Reset Option:** Reset the game at any point to start a new game.
- **Dynamic Player Switching:** The active player is visually indicated, and the turn automatically switches after certain actions.
